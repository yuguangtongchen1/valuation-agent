## 二、归类用多维信息，不把所有东西塞进一棵名称树

以下是基于案例的采购建模建议，不是这些工作室发布的统一标准。

保留项目→区域/展项→装置或服务→报价明细的原始包含关系。另设可检索的采购分类，两者不能互相替代。例如“未来港”是展项名称，“三维动画制作”才可能是其服务类型。层级随证据深度展开，不强制三级。

每行同时理解：

1. **交付对象**：实体展具、数字资产/成片、可运行程序、设备、集成服务、设计成果或运营服务。
2. **功能用途**：承载陈列、空间围合、导览、知识解释、品牌叙事、交互反馈、声光呈现等。
3. **工作阶段**：研究策划、概念设计、深化设计、原型验证、制作、安装调试、部署运营、维护、拆除。相同对象在不同阶段并非同价。
4. **实现链路**：输入（按钮/语音/感应/数据）→逻辑（触发/识别/生成/控制）→输出（图像/声音/机械动作）→载体（屏/投影面/实体）→集成与运行。
5. **成本相关约束**：材质构造、尺寸、像素/分辨率、屏面数量、时长、帧率、内容复杂度、并发、接口、工期、交付文件、版权、现场服务。原件没写则留空。
6. **计价与关系**：整包、组件、工序、版本；元/项、元/秒、元/套、元/平方米、人月等分别保存。组合包含关系不是价格等价关系。

建议主分类可覆盖：研究与体验设计；空间与展具制作；视听设备；数字内容制作；交互与实时软件；机电与动力装置；系统集成；现场运营。多专业整包有主类与组成项，但不得给未标价组件分摊价格。

## 三、容易误解的词与匹配边界

| 表达 | 正确处理 | 禁止直接等同 |
|---|---|---|
| immersive / 沉浸式 | 体验性质；再查具体交付与技术 | VR、投影、互动软件的任意一种 |
| interactive / responsive | 查输入与反馈链，可包含不触摸的感应 | 有声画面、循环播放影片 |
| anti-interactive | 结合行为描述理解，可能是对移动反向响应 | 没有交互系统 |
| generative / 生成式 | 分清制作时生成素材与运行时实时生成 | AI生成影片＝实时生成应用 |
| installation / 装置 | 查是现场实物、系统还是影片内数字构图 | 文案出现装置即采购硬件 |
| digital sculpture / 数字雕塑 | 数字作品/资产/程序，核时间行为和载体 | 实物雕塑、树脂打印 |
| kinetic / 动态 | 分清机械运动与图像动画 | 动画制作＝机械驱动 |
| mapping | 实体投影对位；上下文另可能是模型贴图 | UV贴图、墙面UV打印、投影校准互为同义 |
| naked-eye 3D / 裸眼3D | 核视点、屏幕几何与交付内容 | 双目立体、投影映射、普通三维动画完全同价 |
| scenography / 空间叙事 | 范围可能含空间、道具、灯光与内容设计 | 一概硬装施工或一概舞美搭建 |
| fixture / 展具 | 先看是否含传感器、显示、控制与定制结构 | 普通柜体价格可以覆盖交互展桌 |
| asset / 模型 / 材质 | CG上下文通常是数字资产或着色贴图 | 实体模型、板材采购 |
| CMS / 媒体系统 / 播控 | 核内容管理、编排、播放、控制各自职责 | 一台播控服务器等于完整软件系统 |
| brand / IP / 地点 | 保留上下文与授权约束 | 作为主要物料分类或唯一检索词 |

同义关系应限定上下文，例如：
- “三维资产制作—数字模型搭建”在CG交付一致时可归同类；“沙盘模型制作”不可自动并入。
- “声控展项—语音交互装置”可作候选；声音响度触发、语音识别、语义对话仍是不同实现。
- “提拿感应展台—取物触发陈列”可作候选；不能默认传感器一定采用称重，案例里的技术不外推到新报价。
- “柔性屏花瓣装置—开合屏机械雕塑”可识别同类组合；普通OLED屏只提供部分组件参考。
- “多屏内容适配—异形屏转制”可能同类；重新建模、镜头重做、交互逻辑新增不应被缩成简单转码。

## 四、模型介入的逐行理解流程

先读取原行、表头、合并分组、相邻行、图像和脚注，定位采购语义。不要把展项标题广播成所有行的分类，也不要把每行都回退到同一个“大类参考”。

模型输出必须包含原文定位、标准对象、交付类型、阶段、结构组成、规格、价格范围及不确定字段。把图片观察与文字证据分开；图片只能说明可见几何/组成，不能证明隐藏结构、材料牌号、品牌型号。尺寸移入规格栏，工艺栏保留材料/结构/加工/安装，显示不重复，但原文不丢。

检索分层：同对象同交付→同功能与实现→组合内组件。名称相似仅用于召回；对用途、阶段、材料、配置、计价单位逐一重排。跨物理/数字交付、安装/拆除、整体/零件的候选不能因共同名词排在精确参考前。

关系标签至少区分：
- 同类参考：交付对象与用途一致，进一步列参数差异。
- 条件相似：用途接近，但实现/阶段/配置不同，必须解释条件。
- 部分子件：只覆盖组合中的某个部件，标明对应子件与未覆盖范围。
- 整包参考：范围整体相近，保留总价，不能伪装分项单价。
- 不可比：不同采购对象/阶段，排除；不能为了每行有结果强配。

模型不能凭理解制造价格。总额与数量明确、属于同一行且数量非零，可计算单价并标来源为推算；空值与真零价分开，合并小计不得逐子项重复除。金额按已确认人民币元依据，研究案例本身不参加价格运算。

新报价入库后，自身URL、文件哈希及整个报价版本组必须排除；同一采购的重复附件不增加样本。各版留存，只有当前版启用，不把版本差异当多个独立市场报价。

## 五、用反例检验理解，而不是只增加命中数量

下列人工设计验收题用于后续引擎回归，不是本轮已经运行的算法效果：

| 新报价描述 | 应识别 | 不应优先召回 |
|---|---|---|
| 发布片中的粒子雕塑与品牌符号演绎 | CG内容与动画工序 | 实物雕塑、发光字制作 |
| 取起产品后生成专属诗句并投射到布面 | 感应+生成程序+视听呈现组合 | 仅普通投影机、固定宣传片 |
| 开合花瓣OLED装置 | 机械显示组合、内容及集成 | 单屏售价当整套价格 |
| 听到观众词语后改变场景 | 语音交互与场景响应 | 只有配音的影片 |
| 门店动态内容排期、异形屏自动适配 | 内容管理/生成/多端部署 | 每秒CG报价覆盖整个系统 |
| 树脂打印扫描地貌并配合灯光 | 扫描数据+实体制作+灯光 | 纯数字模型价格 |
| 360°火山影片及声光联动 | 内容与呈现系统分别看 | 因360°直接匹配VR头显 |
| 入口区域：金属烤漆立体字 | 导视标识制作，入口只是位置 | 入口改造整包、场馆运营 |
| 展墙内可调展陈系统 | 展示支架/活动平台组合 | 因含“展墙”就只匹配墙面饰材 |
| 带铜质饰面的旋转地台 | 承载结构+旋转机构+饰面 | 铜板原材价当整套价格 |

检查精度、错配类型、未命中原因和响应时间；不能把“有历史参考”当成“价格可直接比较”。本轮研究没有运行服务器，也不宣称以上验收全部通过。

## 六、应用范围与后续边界

本指南写入采购Skill参考层，让模型处理非标报价时先理解交付语义，再使用检索工具。它不等于模型权重训练，也不等于服务器匹配引擎已经更新。CLI没有调用模型时，不能宣称仅凭新增文档就自动具备这些推理能力。

官网来源应作为语义参考库单独保存，用户合同/报价作为私有价格证据库；二者不可混淆。厂家/供应商关系以用户原件为准，官网项目中的客户、创意工作室、技术合作方、实体制作商分角色记录，不擅自关联为本公司的供应商。
