# 分级归类与估价：内部实施规则

这是采购历史参考方法，借鉴海关的证据判断顺序；不是海关税号申报或法定完税价格结论。树的深度由区分实际交付物所需的信息决定，不固定三级。材质、型号、参数是可交叉筛选的属性，不强行复制出大量同义类目。

## 先确定对象，再选择类目

每份原件先辨认项目标题、模块标题、物料或服务行、配置子行、备注、合计、优惠与版本，不按固定列号套模板。名称/规格合并列可以拆为规范字段，但必须同时保留原单元格和拆分依据。只有型号的子行沿明确父项关联；品牌、尺寸、施工人数不能因为出现在首列就自动成为物料名称。未标价的子件保留，不能分摊整包价格来补。

归类依据应能回答：实际做什么、包含什么、不包括什么、是整体还是组成部分、技术上是什么、按什么计费。项目名和采购人的使用背景提供上下文，不能替代产品实际功能。先处理类目定义中的包含/排除条件，再在同一父类下比较具体细类。

这一顺序来自 [WCO 六项总规则](https://www.wcoomd.org/-/media/wco/public/global/pdf/topics/nomenclature/instruments-and-tools/hs-interpretation-general-rules/general_rules_interpret_hs.pdf?la=en) 和 [中国税则总规则及类章注](https://gss.mof.gov.cn/gzdt/zhengcefabu/202412/P020241230574609162479.pdf)。后者使用2025版研究归类结构，不用于宣称2026税率。

| 海关判断方法 | 内部产品中的落点 | 不机械照搬的部分 |
|---|---|---|
| 规则一：条文与注释先行 | 类目有定义、包含、排除、证据要求；标题只帮助导航 | 不把关键词命中当作结论 |
| 规则二：未完整/未组装、混合材料 | 保留整机/散件/组件角色及实际交付状态；多材料作为属性 | 尚不清楚组成关系时不推定整包 |
| 规则三：具体描述、基本特征、剩余情形 | 细项优先；组合按功能贡献和明确范围判断，保留其他部分 | 内部编号没有法定顺序，不能用“编码靠后”打破平局；也不能只按最高金额定本质 |
| 规则四：相似对象 | 在明确没有精确对象后扩展同功能、技术或工艺候选 | 相似参考仍标差异，不自动当同价 |
| 规则五：容器与包装 | 判断包装是否包含、独立收费或可重复使用，避免重复计价 | 项目运输箱不当然等于随货普通包装 |
| 规则六：同层比较 | 先确认共同父类，再比较其下同层细项，逐级下钻 | 不把某细项和另一个大类直接视为等价 |

## 组合、零件与功能单元

“同一个项目”“同一合同”“同时交付”本身不足以证明所有内容是同一装置。需保留组成清单、每部分功能、连接关系和独立报价。主要功能、共同完成的一种明确功能、辅助功能分别判断；独立完成其他功能的设备仍保留自身身份。这借鉴 [澳大利亚海关功能单元指南](https://www.abf.gov.au/tariff-classification-subsite/files/Guides/classifying-functional-units.pdf) 对实际功能、必要组件、辅助设备及完整设备清单的区分。

内部例子：显示系统可以包含屏体、处理器、发送卡、结构及布线。系统整包价与其中一根线的单价属于不同计价对象。地台与包边整包不能作为独立收口条价格。角色建模绑定、角色动画、材质灯光、后期合成、最终渲染分别保留交付范围，即使源表使用同一个合并标题。

## 每条匹配的证据链

1. 来源：原表→台账行→同格全部文件/图片→原页/原表格行，绑定内容摘要和版本。
2. 对象角色：整项、组件、辅助材料、服务、费用汇总、版本替换或无价配置。
3. 功能与技术细类：实际作用和工作阶段，排除仅同材料但用途不相符的项。
4. 规格配置：型号、结构、尺寸、功率、防护、屏幕/像素/刷新率、配置组合；单位先规范，原读数不改。
5. 范围与计费：采购/租赁、安装/拆除、运输、制作步骤、时间/次数及每套组成。
6. 结果：直接可比、存在差异的同类、仅部分工作、独立子件、整包或工艺线索。

缺少属性与属性明确不同分别表达；缺失不能当一致。名称别名先帮助召回，只有后续证据相符才提升等级。人工别名表中的增删是有版本的采购意见，不自动覆盖原件名称或宣告所有配置相同。

## 检索与估价顺序

遍历已绑定的历史清单；先找同型号/同规格与相同交付，随后扩展技术细类、功能父类，再拆有明确组成的子件，最后显示工艺线索及未收录/缺报价证据。记录扫描的价格行数、使用的归类链、差异和是否确实执行飞书补检；缓存检索不能冒称实时查遍飞书。

价格顺序借鉴 [WTO估价解释性说明](https://www.wto.org/english/docs_e/legal_e/20-val_02_e.htm) 的逐步适用、数量及商业层级差异需要证据支持，以及 [英国海关相似货物实例](https://www.gov.uk/guidance/customs-valuation/examples-of-similar-goods) 对功能、质量和可替代性的判断。内部不照搬法定最低价格选择，也不凭固定百分比补规格差价。零件参考只覆盖该部分，不能代表整包装置。

公司已确认的台账含税人民币和合同原币金额直接关联，税费与汇率不重审、不作为清洗拦截。明确不同币种的单价不裸比；需要人民币单项价时必须有已确认换算依据，不能用合同总额倒推后伪称原单价。

## 报告与模型复核

默认只输出可展开的比价表和Excel；不在表格下添加采购建议或分析段落。只有用户明确要求报告时，才输出“已明确的信息、需澄清的输入、价格观察、相关供应商、参考范围与差异、没有参考的原因及动作”。单条历史报价只能说明与该记录的差异，不代表市场高低。多项目也需先排除共享源、版本、整包/子项重计。无参考不能直接断言完全非标。

Codex 在每份非标原件上利用模型重新辨认字段角色和实际交付内容；可复用已识别文本与图像，只有疑点回原页。规则检索给候选而不替代语义复核。把复核输出作为带原读数、定位、修改前后值及原因的JSON补丁，通过来源校验后入库；不凭模型理解生成原件不存在的型号、数量或价格。

## 研究边界

已研究公开六项总规则、类章注/零件及功能单元、注释与归类意见的作用、相同/相似及有证据调整的估价顺序。[WCO品目注释说明](https://www.wcoomd.org/en/topics/nomenclature/instrument-and-tools/tools-to-assist-with-the-classification-in-the-hs/explanatory-notes.aspx) 表明完整注释需订阅；本次未声称读完受限的五卷全文、所有商品裁定或所有国家税则。方法来源与公司业务证据分开，外部资料不作为公司价格来源。

## 2026-11-09 增补

来源物理行身份与物料语义身份分离；去重必须有同一原表位置与内容摘要依据，不能仅凭相同价格配置。精确型号保留候选位，附带差旅不改变顾问服务主对象，租赁/制作、撤场/搭建、整机/子件金额分开判断。0.4元/平米·场等低费率按原计价次数表达，不任意放大；RVV规格小数逗号只在明确线材语法中规范。多路召回参考[Elastic检索方法](https://www.elastic.co/docs/solutions/search/hybrid-search)，结构化属性复核参考[Ditto论文](https://www.vldb.org/pvldb/vol14/p50-li.pdf)；本地实现不意味着已部署这些外部系统。

装饰定制铁艺梯子与施工登高/租赁梯具分开；同类定制造型可召回，但高度或计价单位不同保留差异，不直接判高低。原件未具名赠送、同源确认函和未细分增补服务按实际档案角色保粗，不虚构采购物料。
