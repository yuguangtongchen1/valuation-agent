# 采购归类路径：海关方法的适用转化

研究日期：2026-11-12。适用于展陈物料、装置、硬件、数字内容与服务的内部采购分类；不是海关申报编码结论。沿用用户归类表的节点标识，新增细类需保留父节点与映射。不能把整个项目按最贵的模块改写成一种物料。

## 依据与边界

- [WCO 归类总规则](https://www.wcoomd.org/~/media/wco/public/global/pdf/topics/nomenclature/instruments-and-tools/hs-interpretation-general-rules/general_rules_interpret_hs.pdf?la=en)：规则1先看品目条文和类章注；规则2处理未完成品、拆散品与混合材料；规则3依次处理具体描述、本质特征与同等候选；规则6只比较同级子目。规则4的类似货品是前序规则无法解决后的后备手段，不是先用模糊名称代替分析。规则3(c)的税目数序兜底不适用于内部估价。
- [加拿大归类方法 D10-13-1](https://www.cbsa-asfc.gc.ca/publications/dm-md/d10/d10-13-1-eng.html)：先掌握组成和功能，再逐层选择品目、子目，不跨层挑选。国际协调层与本国细分层应区分。
- [加拿大功能机组 D10-13-2](https://www.cbsa-asfc.gc.ca/publications/dm-md/d10/d10-13-2-eng.html)：围绕共同明确功能判断组件联系；不服务该功能的辅助设备不能自动并入。文中合同与单价等条件是当地具体政策，不推成全球统一要求。采购中同一展馆、同一合同并不自动等于一个功能机组。
- [美国 CBP N334531](https://rulings.cbp.gov/ruling/N334531)：复合桌案例综合桌面作用、重量、价值等判断本质特征；价值是因素，不是唯一裁决。该条通过官方搜索索引读取，直接页面受访问限制。
- [英国电气设备分类指南](https://www.gov.uk/guidance/classifying-electrical-equipment-for-import-and-export)：设备设计用途、实际能力、是否为部件和是否具备完整处理功能影响路径。显示模组与完整显示系统不能仅凭共同包含 LED 就作等价项；具体编码需另按适用法域核对。
- [欧盟 CLASS](https://taxation-customs.ec.europa.eu/online-services/online-services-and-databases-customs/classification-information-system-class_en) 与 [EBTI](https://taxation-customs.ec.europa.eu/online-services/online-services-and-databases-customs/european-binding-tariff-information-ebti_en)：通过分类资料和裁定核对事实，记录适用时间、法域和货品条件；他人裁定不是本项目自动有效的结论。
- [中国海关预裁定办事指南](https://online.customs.gov.cn/static/pages/guides/000729004001/000729004001.html)：名称、型号、规格、工作原理、功能、用途构成判断资料。专家复核应追问影响结论的具体事实。
- [美国 CBP H320225](https://rulings.cbp.gov/ruling/h320225)：原产地的实质性改变讨论名称、特性、用途变化，与税则归类不是同一个问题；通过官方搜索索引读取。

## 模型必须执行的归类链路

1. **确定本行实际交付对象**：读名称、工艺、规格、图片、合同范围和排除条款；分清地点/品牌背景与采购对象。图片只支持可见构造，不能推测未标材料、尺寸、型号。
2. **确定交付状态与边界**：整机、专用部件、耗材、组合系统、服务、数字资产，及新制/维修/租赁/拆除。合同整包与行级分项保留父子关系。
3. **比较同层候选**：按用户分类树从父类下钻，记录入选和被排除路径及理由。混合合同不能因一个词命中而归入任一单件。
4. **判断主功能和本质特征**：回答“买来完成什么任务”“移除哪一模块使主要交付失败”。综合功能、不可替代性、组成、价值、数量与体量；价格最高不能单独决定。
5. **处理多功能与高价值模块**：有明确主功能则以主功能定位、其他模块作组成；无明确主功能保留组合类别。高价值模块作为独立配置/子件，只有原件独立定价才具有分项价格。不可倒摊整包造出子件价。
6. **规格作为比较条件**：材质、尺寸、功率、点间距、帧率、时长、承重、加工方式、品牌型号、数量与单位分别保存。缺失不当相同。
7. **确定参考角色**：同交付范围、组合和计费方式才考虑价格比较；其他明确标为规格差异、整包或子件参考。先排除自身来源、停用版本和重复采购来源。
8. **留下可审计判断**：采购对象、路径、原文证据、主功能、关键模块、排除候选、剩余疑点、价格范围。规则召回不足时让模型回读原文判断，不以规则未命中结束。

语义判断建议结构（研究契约，并非已上线的新 API）：`object`, `delivery_scope`, `classification_path`, `primary_function`, `essential_modules`, `value_evidence`, `evidence_spans`, `rejected_paths`, `comparison_role`, `unresolved_decisive_fields`。每个实质判断引用原文；无证据的价格和模块占比不得填写。

## 哪些变化需要重新判断

|变化|路径与比价处理|
|---|---|
|固定地台变电动旋转展台|主要功能、机构变化，重新选择机械展具路径|
|显示模组变含处理与控制的整屏|部件变整机，分别归类和计价|
|播控主机变影片制作|实体设备变数字服务，跨类排除|
|新制造型墙变原墙拆除|交付行为变化，不作同价参考|
|钢木地台更换昂贵铜饰面|核心承重用途未必变化；保留饰面差异，不直接按铜材归类|
|P4变P6、功率/尺寸变化|先保留产品路径，检查细类及性能、价格可比性；不自动认定税号改变|
|品牌、项目名称或合同价格变化|本身不应改变功能归类；品牌型号仍是比价参数|
|外观类似但内部材料未知|不能认定同材；补具体关键事实或降为弱参考|

## 专家问答与 QA

|问/测试|应有判断|
|最贵的是饰面，归到饰面吗？|不能仅按价值；先判断采购的是承重平台还是独立饰面施工。|
|同一个展项里的所有设备可算整机吗？|共同项目背景不够；验证明确功能和互相关系，服务与设备另保留。|
|投影机吊架能参考投影机价吗？|不能；安装附件独立路径。|
|LED模组等于LED屏吗？|不能；需看控制、处理、箱体和实际供货边界。|
|只写“模组”怎么办？|不自动猜为LED；读上下文或留下对象未明。|
|不同叫法是否同类？|以功能、构成、交付行为验证，如电动转台与旋转展台；同类不等于规格、价格相同。|
|模型是实体还是数字？|看打印/浇筑等实物交付与建模/绑定等数字交付证据，不能靠“模型”二字归类。|
|规格原件没有写？|保持缺失；不重复要求补原件不存在的非关键字段。|
|金额变化但对象未变？|路径应保持稳定，金额只参与价格计算和价值证据。|
|源报价刚入库？|必须排除自身及同源变体；版本保留但只启用当前版本，不扩大独立样本数。|

质量验收同时覆盖：别名等价测试、核心功能改变测试、高价饰面干扰测试、整机/部件反例、数字/实体反例、跨作业行为反例、缺失字段、同源与版本泄漏。测试名称和预期必须可读，不能只报命中率。实际全库归类仍需原件证据，本文研究不构成全库已复核的声明。
