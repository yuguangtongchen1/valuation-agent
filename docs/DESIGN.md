# 设计说明

以可操作报价表作为主视觉。选择报价行后，其上下边框向右延伸，包含只属于该行的历史参考；再点参考进入独立详情弹窗。页面其余部分保持安静，避免营销卡片抢占阅读。

- 色板：白色 `#ffffff`、墨色 `#172923`、操作绿 `#16664b`、工具蓝 `#2463cb`、差异黄 `#fff0b5`、浅灰绿 `#f3f7f5`。
- 字体：中文优先系统 PingFang SC / Hiragino Sans GB / Microsoft YaHei；命令用系统等宽字体。无外部字体请求。
- 布局：1180px 内容宽度，中文正文左对齐；标题、说明、数据分别建立层次。价格与单位单行，规格可换行。
- 移动：报价行改为纵向信息块，参考仍紧随所选行，避免横向滑动。
- 交互：原生按钮与 dialog；焦点可见、Escape 关闭并返回触发按钮；复制结果通过可见文字及 live region 告知。无自动动画，尊重减少动态效果偏好。
- 内容：独立合成案例，区分同类规格差异、范围差异和部分子件。不会声称市场合理价或生产后台已接入。
