变成能回查的经验。

使用你自己的资料建立关联。
每条参考都能回到项目和原始明细。

  1. 1

    接入一份新报价

    导入报价文件，或通过已授权的飞书来源读取。保留项目、装置与 BOM 的包含关系。

  2. 2

    按实际内容归类和检索

    结合用途、材质、型号、工艺和组合查找相似项。整包、分项和部分子件分别呈现。

  3. 3

    回到明细，核对比价表

    在表格中查看历史供应商、原始价格和规格差异。点击参考项下钻到完整报价，保留整包和分项的区别。

一行安装并打开原版工作台 · 0.2.11
python3 -c "import pathlib,venv,os,subprocess;d=pathlib.Path.home()/'.valuation-agent/workbench';venv.create(d,with_pip=True);p=str(d/('Scripts/python.exe' if os.name=='nt' else 'bin/python'));subprocess.run([p,'-m','pip','install','valuation-agent[excel] @ https://codeload.github.com/yuguangtongchen1/valuation-agent/zip/63eb660b9108c013ed637899072f0a9e5f68546b'],check=True);subprocess.run([p,'-m','valuation_agent.cli','launch'],check=True)"

将命令交给 Codex 执行，或直接在终端运行。Windows 将开头的 python3 换成 py。需要 Python 3.9+、网络连接；无需 Git、Node.js 或自行部署服务器。

首次打开后输入管理员单独发给你的访问码。历史数据库留在服务器，按权限查询；请保持启动进程运行。飞书导入另需你自己的飞书授权。
